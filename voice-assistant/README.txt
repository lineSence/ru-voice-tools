RU VOICE ASSISTANT — локальный голосовой ассистент (русский)
============================================================

Пайплайн: микрофон -> Vosk (распознавание) -> LLM -> Silero (озвучка).
Всё локально, GPU не нужен (работает на процессоре).
Настройки сохраняются автоматически в settings.json рядом с программой.

ЧТО НУЖНО
  - Windows 10/11 (или Linux/macOS)
  - Python 3.10–3.12  →  https://www.python.org/downloads/
    При установке поставьте галочку "Add python.exe to PATH".
    (Если Python нет, launch.bat попробует установить его через winget.)
  - Интернет при первом запуске и первом диалоге:
      библиотеки ~1 ГБ, модель распознавания ~45 МБ,
      языковая модель 2.5 ГБ (Qwen3-4B) или 7.5 ГБ (Gemma-3-12B),
      синтезатор Silero ~140 МБ.
  - Место на диске: ~5 ГБ (или ~10 ГБ с обеими локальными моделями).
  - ОЗУ: от 8 ГБ для Qwen3-4B; от 16 ГБ для Gemma-3-12B.

ЗАПУСК (Windows)
  1. Распакуйте папку ru-voice-assistant.
  2. Двойной клик по launch.bat (первый раз — установка 10-20 минут).
  3. Откроется вкладка http://127.0.0.1:7861
  4. Ярлык: правой кнопкой по launch.bat -> Отправить -> Рабочий стол.

ЗАПУСК (Linux/macOS)
  ./launch.sh

КАК ПОЛЬЗОВАТЬСЯ
  - Нажмите на значок микрофона, говорите вопрос, остановите запись —
    ассистент сам распознает, ответит и озвучит.
  - Можно писать вопрос текстом (Enter).
  - Браузер попросит доступ к микрофону — разрешите.

РЕЖИМЫ LLM (модели не зашиты — выбирайте любые)
  - "Hugging Face GGUF": репозиторий + имя файла .gguf, скачается само.
    По умолчанию: bartowski/Qwen_Qwen3-4B-Instruct-2507-GGUF (~2,5 ГБ).
    Другой пример: bartowski/google_gemma-3-12b-it-GGUF,
    файл google_gemma-3-12b-it-Q4_K_M.gguf (~7,5 ГБ, нужно 16 ГБ ОЗУ).
  - "Локальный файл .gguf": путь к уже скачанной модели, напр.
    C:\models\model-q4_k_m.gguf
  - "LiteLLM-прокси": ваши облачные модели — Base URL
    (по умолчанию http://127.0.0.1:4000/v1), API key (если есть), имя модели.
    Внимание: ключ хранится в settings.json открытым текстом.

WAKE WORD
  - Поставьте галочку "Wake word" — ассистент слушает системный микрофон
    и ждёт кодовое слово (по умолчанию "ассистент", можно поменять).
  - Скажите wake word, затем сразу вопрос. Ответ прозвучит из динамиков
    компьютера (и появится в браузере, если вкладка открыта).
  - Во время ответа ассистент себя не слушает (защита от эха).
  - Wake word использует микрофон компьютера, а не браузера.

ЗАМЕТКИ
  - Первый голосовой вопрос долгий: скачиваются модели. Дальше — быстро.
  - Если распознавание падает с ошибкой "Read timed out" (alphacephei.com
    отвечает медленно): программа сама повторит скачивание с докачкой.
    Если не помогло — скачайте модель вручную в браузере:
      https://alphacephei.com/vosk/models/vosk-model-small-ru-0.22.zip
    и распакуйте так, чтобы получилась папка
      C:\Users\<имя>\.cache\vosk\vosk-model-small-ru-0.22\
    После этого скачивание не потребуется.
  - Точность распознавания можно поднять большой моделью Vosk
    (vosk-model-ru-0.42, ~1.5 ГБ): скажите автору пакета, заменим.
  - Если GUI падает с "code 502" — отключите прокси/VPN или обновите
    app.py (в новых версиях это исправлено).
  - Порт 7861; подкаст-приложение (порт 7860) можно держать открытым параллельно.
