RU VOICE ASSISTANT — локальный голосовой ассистент (русский)
============================================================

Пайплайн: микрофон -> Whisper или Vosk (распознавание) -> LLM (+ поиск в
интернете, если нужен) -> Silero (озвучка по предложениям, пока модель пишет).
LLM и Whisper работают в KoboldCpp на видеокарте через Vulkan (AMD, NVIDIA,
Intel — CUDA не нужна) или на процессоре. Всё локально, в сеть — только поиск.
Настройки сохраняются автоматически в settings.json рядом с программой.

ЧТО НУЖНО
  - Windows 10/11 (или Linux/macOS)
  - Python 3.10–3.12  →  https://www.python.org/downloads/
    При установке поставьте галочку "Add python.exe to PATH".
    (Если Python нет, launch.bat попробует установить его через winget.)
  - Свежий драйвер видеокарты (для AMD — Adrenalin), в нём есть Vulkan.
  - Интернет при первом запуске (дальше всё работает без сети, кроме
    поиска в интернете):
      библиотеки ~1 ГБ, движок KoboldCpp ~120 МБ (распакуется в ~310 МБ),
      Whisper large-v3-turbo ~570 МБ, Vosk ~45 МБ, Silero ~140 МБ,
      языковая модель 2.5 ГБ (Qwen3-4B) или 7.5 ГБ (Gemma-3-12B).
  - Место на диске: ~6 ГБ (или ~11 ГБ с обеими локальными моделями).
  - Видеопамять: Qwen3-4B + Whisper turbo занимают ~5,5 ГБ — на 8 ГБ влезают
    целиком. Gemma-3-12B целиком не влезет: часть слоёв останется на
    процессоре (это делается само).

ЗАПУСК (Windows)
  1. Распакуйте папку ru-voice-assistant.
  2. Двойной клик по launch.bat (первый раз — установка 10-20 минут).
  3. Откроется вкладка http://127.0.0.1:7861
  4. Ярлык: правой кнопкой по launch.bat -> Отправить -> Рабочий стол.

ЗАПУСК (Linux/macOS)
  ./launch.sh

ОБНОВЛЕНИЕ
  Распакуйте новую версию поверх старой папки (с заменой файлов).
  Настройки (settings.json), движок (engine\) и скачанные модели
  сохранятся; launch.bat при первом запуске сам доустановит новые
  библиотеки (1–2 минуты).

КАК ПОЛЬЗОВАТЬСЯ
  - Нажмите на значок микрофона, говорите вопрос, остановите запись —
    ассистент сам распознает, ответит и озвучит.
  - Можно писать вопрос текстом (Enter).
  - Браузер попросит доступ к микрофону — разрешите.
  - Ответ появляется в "Диалоге" по мере того, как модель его пишет.

ДЛИНА И ХАРАКТЕР ОТВЕТОВ (СИСТЕМНЫЙ ПРОМПТ)
  - Раздел "🧠 Характер и длина ответов": системный промпт — инструкция
    для модели, как отвечать. Меняйте как хотите: "Ты — учитель физики,
    объясняй на примерах", "Обращайся на ты", "Отвечай с юмором".
    Пустое поле = стандартный промпт.
  - Кнопки-заготовки:
      "Коротко" — 1–3 предложения на любой вопрос (как в прошлых версиях);
      "Сбалансированно (стандарт)" — на простой вопрос коротко, а на
        "расскажи подробно", "объясни", "как сделать..." — развёрнуто,
        по шагам и с пояснениями;
      "Подробно" — всегда обстоятельно, с примерами и советами.
  - "Максимальная длина ответа (токенов)": 1024 по умолчанию
    ≈ 2500–3000 знаков ≈ 2–3 минуты речи. Если ответ упёрся в предел,
    под ним в "Диалоге" появится ✂️ с подсказкой — увеличьте ползунок.
  - Длинный ответ не нужно ждать целиком:
      через wake word озвучка начинается с первого предложения, пока
        модель пишет остальное;
      в браузере звук включится, когда ответ готов (синтез идёт
        параллельно с генерацией, так что ждать почти нечего).
  - Ассистент знает текущие дату и время: "который час?", "какой
    сегодня день недели?", "сколько дней до Нового года?".
  - Контекст модели теперь 8192 токена (было 4096 — обновится само):
    влезают и длинные ответы, и найденное в интернете. Модель занимает
    чуть больше видеопамяти (~0,6 ГБ для Qwen3-4B).

ПОИСК В ИНТЕРНЕТЕ
  - "🌐 Поиск в интернете" — три режима:
      "Автоматически — модель решает сама" (по умолчанию): погода,
        курсы валют, новости, цены, версии программ, свежие события —
        ищет; беседа, объяснения, расчёты, стихи — отвечает сразу;
      "Только когда прошу": ищет, только если сказать "найди...",
        "поищи в интернете...", "погугли..."; про свежие данные без
        просьбы скажет, что точных данных нет, и предложит поискать;
      "Выключен".
  - "Найди ..." / "поищи в интернете ..." — поиск в любом режиме,
    кроме "Выключен".
  - Пока ищет: "🌐 Ищу в интернете: «запрос»" — в "Диалоге" и в строке
    wake word. Под ответом видно, откуда взято:
    "🔎 Искал в интернете «погода в Москве завтра»: gismeteo.ru, ...".
  - Ключи и регистрация не нужны: библиотека ddgs опрашивает сразу
    несколько поисковиков (Google, DuckDuckGo, Yahoo, Brave и др.) и
    берёт ответы тех, что ответили; ассистент читает 3 лучшие страницы.
    Если поисковики недоступны — ответит по своим знаниям и предупредит
    (⚠️ под ответом).
  - Прокси/VPN: берётся из настроек Windows (как у браузера) или из
    переменных HTTPS_PROXY / HTTP_PROXY. VPN "на весь трафик" работает
    сам. Если поиск всё время пишет ⚠️ — попробуйте включить VPN.
  - Поиск добавляет к ответу 5–15 секунд (поиск + чтение найденного).
  - Маленькая модель иногда ошибается, искать или нет: тогда просто
    скажите "найди ...".

РАСПОЗНАВАНИЕ ВОПРОСА
  - "Whisper" (по умолчанию) — понимает английские слова внутри русской
    речи: "как настроить MIDI-синтезатор", "Python на Windows", "USB".
  - "Vosk" — быстрее и легче, но знает только русские слова
    ("MIDI" у него превращается в "видео").
  - "Подсказка для Whisper" (в "Настройках моделей") — впишите термины,
    которые часто говорите: названия программ, марки, имена. Whisper
    будет узнавать их увереннее.
  - Модель Whisper: ggml-large-v3-turbo-q5_0.bin — для видеокарты.
    Если считаете на процессоре и распознавание долгое —
    ggml-small-q8_0.bin (быстрее, но английские слова узнаёт хуже).
  - Английские слова и числа в ответах озвучиваются по-русски:
    "Windows" -> "виндоус", "2024 году" -> "две тысячи двадцать четвёртом году".

ВИДЕОКАРТА (Vulkan)
  - "Где считать LLM и Whisper": "Видеокарта (Vulkan)" или "Только процессор".
  - Строка "⚙️ Движок KoboldCpp" показывает, что происходит: скачивание,
    запуск, на чём считает ("видеокарта AMD Radeon RX 580 (Vulkan)")
    и сколько секунд занял последний вопрос.
  - Если там написано "Vulkan не нашёл видеокарту" — обновите драйвер.
    Если Vulkan падает — ассистент сам перейдёт на процессор и напишет об этом.
  - "Слоёв LLM на видеокарте": -1 = авто (сколько влезет), 0 = LLM на
    процессоре, Whisper всё равно на видеокарте.
  - После смены модели или режима движок перезапускается сам (10–60 с);
    кнопка "🔄 Перезапустить движок" — если что-то пошло не так.
  - Движок скачивается в папку engine\ рядом с программой; лог —
    engine\koboldcpp.log (пришлите его автору, если что-то не работает).
  - Уже есть свой KoboldCpp? Впишите путь в settings.json:
    "kobold_path": "C:\\koboldcpp\\koboldcpp-nocuda.exe"

РЕЖИМЫ LLM (модели не зашиты — выбирайте любые)
  - "Hugging Face GGUF": репозиторий + имя файла .gguf, скачается само.
    По умолчанию: bartowski/Qwen_Qwen3-4B-Instruct-2507-GGUF (~2,5 ГБ).
    Другой пример: bartowski/google_gemma-3-12b-it-GGUF,
    файл google_gemma-3-12b-it-Q4_K_M.gguf (~7,5 ГБ).
  - "Локальный файл .gguf": путь к уже скачанной модели, напр.
    C:\models\model-q4_k_m.gguf
  - "LiteLLM-прокси": ваши облачные модели — Base URL
    (по умолчанию http://127.0.0.1:4000/v1), API key (если есть), имя модели.
    Внимание: ключ хранится в settings.json открытым текстом.

WAKE WORD (голосовая активация)
  - В блоке "Голосовая активация" поставьте галочку "Слушать микрофон
    компьютера" и выберите микрофон в списке (кнопка 🔄 обновляет список).
  - Говорите одной фразой: "Ассистент, какая погода?" — или скажите
    "Ассистент", дождитесь короткого сигнала и задайте вопрос.
  - Слово-триггер ловит Vosk, а сам вопрос дораспознаёт Whisper
    (статус "✍️ Распознаю вопрос") — английские слова не теряются.
  - Можно несколько слов через запятую: "ассистент, компьютер".
  - Ответ прозвучит из динамиков компьютера и появится в "Диалоге".
  - Во время ответа ассистент себя не слушает (защита от эха).
  - Галочка, слово и микрофон сохраняются: после перезапуска wake word
    включится сам.

  ЕСЛИ НЕ СРАБАТЫВАЕТ — смотрите строку состояния под настройками:
  - "Уровень" не растёт, когда вы говорите -> выбран не тот микрофон
    или Windows не даёт доступ: Параметры -> Конфиденциальность ->
    Микрофон -> "Разрешить классическим приложениям доступ к микрофону".
  - "Слышу: ..." — то, что распознал Vosk. Если вместо вашего слова
    там другое (например, "систент") — допишите этот вариант через
    запятую или выберите другое слово ("компьютер" ловится уверенно).
  - В чёрном окне консоли видны строки [wake], [whisper], [engine] —
    пришлите их автору, если что-то идёт не так.

УПРАВЛЕНИЕ КОМПЬЮТЕРОМ
  Раздел «🖥 Управление компьютером». Нужен плеер VLC (videolan.org) — его путь
  находится сам; если нет, укажите путь к vlc.exe. Укажите папку с фильмами
  и нажмите «🔄 Обновить списки» — увидите, сколько фильмов и программ найдено.
  Команды (с wake word или текстом):
    «Ассистент, включи Бегущий по лезвию на полный экран» (или «…в окне»)
    «…пауза», «…продолжи», «…перемотай вперёд на 5 минут», «…назад на 30 секунд»
    «…громче», «…тише», «…выключи фильм», «…на весь экран»
    «…запусти телеграм», «…открой блокнот», «…выключи звук»
    «…заблокируй компьютер», «…выключи компьютер» / «…перезагрузи компьютер»
      (переспросит — ответьте «Ассистент, да»; передумали — «Ассистент, отмени
      выключение» в течение 15 секунд)
  Фильм с английским именем файла по русскому названию находит модель: она
  подсказывает оригинальное название. Если похожих фильмов несколько, ассистент
  спросит какой — ответьте «Ассистент, второй» или назовите год.
  Свои названия: строки «как говорю = что открыть», например
    бегущий по лезвию = Blade Runner
    браузер = C:\Program Files\Google\Chrome\Application\chrome.exe
  Пока ассистент слушает и отвечает, звук фильма приглушается.
  Произвольные команды ассистент не выполняет — только перечисленные.

ЗАМЕТКИ
  - Первый запуск долгий: скачиваются движок и модели (прогресс — в строке
    "⚙️ Движок KoboldCpp"). Дальше — быстро.
  - После обновления launch.bat один раз доставит библиотеку поиска ddgs.
  - Если скачивание Vosk падает с "Read timed out" (alphacephei.com
    отвечает медленно): программа сама повторит скачивание с докачкой.
    Если не помогло — скачайте модель вручную в браузере:
      https://alphacephei.com/vosk/models/vosk-model-small-ru-0.22.zip
    и распакуйте так, чтобы получилась папка
      C:\Users\<имя>\.cache\vosk\vosk-model-small-ru-0.22\
  - Антивирус может долго проверять KoboldCpp при первом запуске — это
    официальная сборка с github.com/LostRuins/koboldcpp (контрольная сумма
    сверяется автоматически).
  - Если GUI падает с "code 502" — отключите прокси/VPN или обновите
    app.py (в новых версиях это исправлено).
  - Порты: 7861 — ассистент, 5011 — движок KoboldCpp (только для этого
    компьютера); подкаст-приложение (порт 7860) можно держать открытым параллельно.
