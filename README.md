# ru-voice-tools 🎙️

Локальные голосовые инструменты на русском языке. Без облаков и API-ключей. Ассистент считает распознавание речи
и LLM на видеокарте через Vulkan (подходят и AMD без CUDA), а без видеокарты — на процессоре.

![Python](https://img.shields.io/badge/python-3.10--3.12-blue) ![License](https://img.shields.io/badge/license-MIT-green) ![Platform](https://img.shields.io/badge/platform-Windows%20%7C%20Linux%20%7C%20macOS-lightgrey)

## Состав

| Пакет | Что делает | Порт |
|---|---|---|
| [`podcast-tts/`](podcast-tts/) | Многоголосые подкасты из текстового сценария `Имя: реплика`. 6 голосов Silero v5, автоударения, склейка в WAV | 7860 |
| [`voice-assistant/`](voice-assistant/) | Голосовой ассистент: микрофон → Whisper/Vosk → LLM (+ поиск в интернете) → Silero. Понимает английские слова в русской речи, wake word, развёрнутые ответы с озвучкой по ходу генерации, редактируемый системный промпт, любые GGUF-модели на видеокарте (Vulkan) или CPU, LiteLLM, автосохранение настроек. Управление компьютером голосом: «включи Бегущий по лезвию» — фильм в VLC на полный экран, пауза, перемотка, громкость, запуск программ | 7861 |

Оба приложения: двойной клик по лаунчеру → сами ставят зависимости → открывают GUI в браузере.

## Быстрый старт

**Требования:** Python 3.10–3.12 (с галочкой «Add python.exe to PATH»), интернет при первом запуске, 2–10 ГБ на диске.

```text
Windows : распаковать → двойной клик launch.bat
Linux   : ./launch.sh
```

Первый запуск ставит библиотеки (10–20 минут), модели скачиваются при первом использовании
(обновление — распаковать новую версию поверх старой: настройки и модели сохранятся):
подкаст-TTS ~140 МБ; ассистент ~120 МБ (движок KoboldCpp) + ~574 МБ (Whisper) + ~45 МБ (Vosk)
+ 2,5–7,5 ГБ (LLM, если выбрана локальная) + 140 МБ (TTS).

## Режимы LLM в ассистенте

Модели не зашиты в код — укажите любую GGUF (репозиторий + файл на Hugging Face или локальный путь)
либо OpenAI-совместимый endpoint (LiteLLM). Проверенные дефолты:

| Модель | Размер | Видеокарта 8 ГБ (Vulkan) | Когда брать |
|---|---|---|---|
| Qwen3-4B-Instruct-2507 (дефолт) | ~2,5 ГБ | целиком в видеопамяти вместе с Whisper | по умолчанию |
| Gemma-3-12B-it | ~7,5 ГБ | вместе с Whisper не влезает — часть слоёв на CPU, медленнее | если 16+ ГБ ОЗУ и важнее качество |
| LiteLLM-прокси | — | не нужна | свои облачные модели |

## Распознавание речи и видеокарта

- **Whisper** (по умолчанию, large-v3-turbo) понимает английские слова в русской речи:
  «как настроить MIDI синтезатор», «USB микрофон», «Python на Windows». Список терминов-подсказок
  редактируется в «Настройках моделей». **Vosk** — быстрее, но только русские слова.
- Whisper и локальную LLM считает один движок **KoboldCpp** (официальная сборка без CUDA, Vulkan + CPU).
  Он скачивается сам в `voice-assistant/engine/` при первом запуске (проверяется sha256) и работает
  в фоне на `127.0.0.1:5011`.
- Строка «⚙️ Движок KoboldCpp» в GUI показывает, на чём реально идёт счёт (имя видеокарты или «процессор»),
  какие модели загружены и сколько занял последний ответ. Если Vulkan не взлетел — движок сам
  перезапускается на процессоре и пишет, что делать (обычно — обновить драйвер AMD Adrenalin).
  Подробности — `engine/koboldcpp.log`.

## Поиск в интернете и характер ответов

- **Поиск без ключей** (библиотека [ddgs](https://github.com/deedy5/ddgs)): три режима — «Автоматически»
  (модель сама решает: погода, курсы, новости, цены, версии программ → ищет; беседа, объяснения,
  расчёты → отвечает сразу), «Только когда прошу» («найди…», «поищи в интернете…») и «Выключен».
  Модель просит поиск одной строкой `ПОИСК: запрос`; ассистент опрашивает сразу несколько поисковиков
  (Google, DuckDuckGo, Yahoo, Brave…), дочитывает три лучшие страницы и отдаёт выдержки модели.
  Под ответом в «Диалоге» — откуда взято. Прокси — из настроек Windows / `HTTPS_PROXY`.
- **Системный промпт редактируется в GUI** («🧠 Характер и длина ответов»), с заготовками
  «Коротко» / «Сбалансированно» / «Подробно» и ползунком максимальной длины ответа (по умолчанию
  1024 токена ≈ 2–3 минуты речи). Дата и время подставляются автоматически.
- **Ответ потоком**: текст появляется в «Диалоге» по мере генерации, а через wake word первое предложение
  звучит, пока модель дописывает остальное. Контекст по умолчанию — 8192 токена.

## Wake word

Блок «Голосовая активация»: галочка → ассистент слушает микрофон компьютера (выбирается
в списке). Говорите одной фразой «Ассистент, какая погода?» — или «Ассистент» → сигнал →
вопрос. Можно несколько слов через запятую. Строка состояния показывает уровень микрофона
и что слышит распознаватель («Слышу: …») — по ней сразу видно, где проблема.
Слово ловит Vosk (лёгкий, слушает постоянно), а сам вопрос после него заново распознаёт Whisper —
поэтому английские слова доходят до LLM правильно. Во время ответа захват приостанавливается (защита от эха). Все настройки (голос, модель,
wake word, микрофон, ключи) автосохраняются в `settings.json`.

## Структура репозитория

```text
├── podcast-tts/          # генератор подкастов (Silero v5)
├── voice-assistant/      # голосовой ассистент (Vosk + Whisper + KoboldCpp + Silero)
├── AGENTS.md             # L0: стартовая инструкция для ИИ-агентов (SEK)
├── wiki/                 # L1–L2: маршрутизация, правила, справочники, архитектура
│   ├── _routing.md       #   триггеры "ключевые слова → какие файлы грузить"
│   ├── _index.md         #   оглавление wiki
│   ├── architecture/     #   устройство пайплайнов
│   ├── references/       #   модели, ссылки, лицензии
│   ├── rules/            #   проверенные правила с ID-тегами
│   └── workflows/        #   процессы (релиз, тестирование)
└── memory/inbox.md       # L3: конвейер черновых наблюдений (SEK)
```

## Документация

Документация организована по схеме **SEK** (Self-Evolving Knowledge, [статья на Хабре](https://habr.com/ru/articles/1041612/)):
агент (или новый контрибьютор) стартует с крошечного `AGENTS.md`, подгружает разделы `wiki/` только по триггерам,
а новые знания рождаются в `memory/inbox.md` и по мере подтверждения промоутятся в `wiki/rules/`.
