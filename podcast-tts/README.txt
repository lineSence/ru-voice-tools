RU PODCAST TTS — многоголосый подкаст на русском, локально и бесплатно
=====================================================================

Движок: Silero TTS v5 (лицензия MIT). Работает на процессоре —
видеокарта не нужна (RX 580 не используется, для этой модели она и не требуется).

ЧТО НУЖНО
  - Windows 10/11 (или Linux/macOS)
  - Python 3.10–3.12  →  https://www.python.org/downloads/
    При установке ОБЯЗАТЕЛЬНО поставьте галочку "Add python.exe to PATH".
    (Если Python нет, launch.bat попробует установить его сам через winget.)
  - Интернет при первом запуске (скачиваются библиотеки ~1 ГБ и модель ~100 МБ)
  - ~2 ГБ свободного места

КАК ЗАПУСТИТЬ (Windows)
  1. Распакуйте папку ru-podcast-tts куда удобно.
  2. Двойной клик по launch.bat.
     Первый запуск: 5–15 минут установки. Следующие — сразу открывается GUI.
  3. Откроется вкладка браузера http://127.0.0.1:7860 — это и есть программа.
  4. По желанию: правой кнопкой по launch.bat → Отправить → Рабочий стол (ярлык).

КАК ЗАПУСТИТЬ (Linux/macOS)
  ./launch.sh

КАК ПИСАТЬ СЦЕНАРИЙ
  Каждая строка:   Имя: текст реплики
  Имена и голоса настраиваются в интерфейсе (до 4 спикеров).
  Строку без имени читает Спикер 1.
  Ударение вручную: знак + перед гласной →  молок+о, зам+ок.

ГОЛОСА (Silero v5)
  aidar (м), eugene (м), baya (ж), kseniya (ж), xenia (ж), random

ЕСЛИ ЧТО-ТО СЛОМАЛОСЬ
  - Удалите файл .venv\.installed и запустите launch.bat снова —
    зависимости переустановятся.
  - Ошибки venv: переустановите Python 3.12 с галочкой "Add to PATH".

КУДА РАСТИ ДАЛЬШЕ
  Если появится видеокарта NVIDIA (4+ ГБ), можно перейти на
  F5-TTS_RUSSIAN или CosyVoice 3 — там клонирование любых голосов.
