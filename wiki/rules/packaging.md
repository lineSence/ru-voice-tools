# Правила: упаковка и лаунчеры

## [PACK-001] launch.bat — только ASCII
Кириллица в .bat ломается кодировками cp866/cp1251/UTF-8. Все сообщения — на английском,
документация для пользователя — в README.txt (UTF-8).

## [PACK-002] torch ставится отдельно и с CPU-индекса
В `requirements.txt` torch не добавлять. В лаунчере:
`pip install torch --index-url https://download.pytorch.org/whl/cpu` — иначе на Windows
приедет CUDA-сборка на гигабайты.

## [PACK-003] Маркер установленности
`.venv/.installed` создаётся только после успешной установки всех пакетов —
повторный запуск мгновенный, оборванная установка перезапускается сама.

## [PACK-004] Нет Python → winget
Лаунчер пробует `py -3`, затем `python`, затем `winget install Python.Python.3.12`
с просьбой перезапустить bat (PATH обновляется только в новом окне).

## [PACK-005] Тест перед отдачей — в песочнице
Чек-лист в `wiki/workflows/release.md`. Минимум: чистый venv + свежий `$HOME`
(проверка всех авто-скачиваний) + HTTP 200 от GUI.
