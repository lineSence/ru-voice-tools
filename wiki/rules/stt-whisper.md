# Правила: Whisper — распознавание вопроса

## [WHSP-001] Роли: Vosk ловит wake word, Whisper пишет вопрос
Vosk small-ru знает только русский словарь: «MIDI» → «видео»/«миде». Whisper large-v3-turbo (`langcode=ru`)
пишет «MIDI-синтезатор», «Python на Windows», «USB микрофон», «VST-плагин для FL Studio», «GitHub»
(проверено на Silero-речи). Vosk остаётся для потокового wake word (дёшево, CPU) и как фолбэк:
Whisper упал/пусто → текст Vosk.

## [WHSP-002] Отрезок для Whisper — по времени слов Vosk
`rec.SetWords(True)` → в `Result()` поле `result: [{word, start, end}]`. Время считается от СОЗДАНИЯ
распознавателя и копится через фразы (проверено: вторая фраза 6,36 с при ожидаемых 6,39).
Абсолютное время = `rec_t0 + start`; `rec_t0` сбрасывается при каждом `new_rec()` (после ответа и mute).
Кольцевой буфер 45 с; отрезок [первое слово wake word − 0,3 с, последнее слово + 0,4 с]. В режиме
«два шага» — только фраза-вопрос. Тест: корреляция отрезка с исходником — начало за 0,3 с до речи.

## [WHSP-003] Wake word из текста Whisper
`strip_wake_text()`: тот же `find_wake`, но только среди первых 3 слов; всё до wake word и он сам
отрезаются вместе с пунктуацией. Пусто (Whisper услышал только слово) → вопрос Vosk.

## [WHSP-004] Галлюцинации на тишине и шуме
Whisper пишет «Субтитры сделал DimaTorzok», «Продолжение следует…», «[музыка]», повторяет подсказку.
`clean_whisper()`: убирает скобки, отбрасывает короткие (< 80 символов) ответы с такими маркерами и эхо
подсказки; в запросе `suppress_non_speech: true`. Короче 1 с whisper.cpp не распознаёт — дополнять
тишиной до 1,2 с.

## [WHSP-005] Подсказка (initial prompt)
Дефолт — русская фраза со списком терминов (MIDI, USB, Python…). С ней «Посоветуй хороший VST-плагин
для FL Studio.», без неё — «Посоветы хороший …». Передаётся в каждом запросе, перезапуск не нужен.

## [WHSP-006] Модели и скорость
Дефолт `ggml-large-v3-turbo-q5_0.bin` (574 МБ) из `ggerganov/whisper.cpp`. Песочница 2 vCPU: turbo
~130 с на фразу, small-q8_0 46–95 с и «MIDI» не узнаёт («меди»). whisper.cpp всегда считает окно 30 с —
время почти не зависит от длины фразы. На видеокарте ожидается порядок секунд (не замерено).
Для CPU-режима UI подсказывает small.

## [WHSP-007] API KoboldCpp
`POST /api/extra/transcribe`, JSON `{"audio_data": base64 WAV, "langcode": "ru", "prompt": "...",
"suppress_non_speech": true}` → `{"text": "..."}`. WAV любой частоты — KoboldCpp сам приводит к 16 кГц.
Есть и OpenAI-вариант `/v1/audio/transcriptions` (multipart: file, prompt, language).
