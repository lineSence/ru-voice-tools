# Правила: управление компьютером голосом (`voice-assistant/pc_control.py`)

## [PC-001] Сначала правила, LLM — только за названием фильма
`answer_and_speak` до LLM вызывает `pc_control.handle(text, cfg, ask_llm)`: `Reply` → короткий ответ голосом
и действие, `None` → обычный ответ модели. Типовые команды разбираются регулярками и нечётким сравнением —
мгновенно и без видеокарты ([CORE-005]). Модель (`llm_short`, без истории) спрашивается только тогда,
когда фильма с похожим именем в папке нет: «Бегущий по лезвию» → «Blade Runner». Ответ «НЕТ» — не нашли.

## [PC-002] Белый список действий, никакой оболочки
Фильм в VLC, ярлык / exe / адрес через `os.startfile` (без аргументов), громкость клавишами
`keybd_event`, `LockWorkStation`, `shutdown /s|/r /t 15`, `/a`, сон. Команды от LLM не исполняются.
Выключение / перезагрузка / сон — только после «да» (`PENDING`, 30 с); «отмени выключение» → `shutdown /a`.
Новых pip-пакетов нет (ctypes, winreg) — маркер установки не поднимали ([PACK-003]).

## [PC-003] Нечёткое имя: ошибки Whisper и кириллица ↔ латиница
`similarity()`: покрытие слов запроса (0,85) + слов кандидата (0,15) по `SequenceMatcher`, числа — только
точно («2049» ≠ «2048»); для разных алфавитов — `skel()` (латинский «скелет»: «дискорд» = «discord»,
«стим» = «steam»). «берущий по лезвия» ~ «бегущий по лезвию» = 0,90. Порог `MATCH_OK` 0,78.
Имена релизов чистит `clean_title()`: год — последний правдоподобный, не первым словом («Blade Runner 2049
2017» → «blade runner 2049», 2017), теги качества отрезаются; файл один в своей папке — имя и по папке.

## [PC-004] Несколько похожих — переспросить
Два лучших ближе `AMBIG_GAP` (0,08) → «Нашлось несколько фильмов: 1 — …; 2 — …» по возрастанию года;
ответ «Ассистент, второй» / год / название в течение 60 с (`PENDING`). Год в исходной команде выбирает сам.

## [PC-005] VLC — свой процесс и HTTP-интерфейс на 127.0.0.1
`vlc --no-one-instance --play-and-exit --fullscreen --video-on-top --extraintf=http --http-host=127.0.0.1
--http-port=7862 --http-password=<случайный>`; порт занят → 7872…7891. Управление — `/requests/status.json`
(`pl_forcepause`, `pl_forceresume`, `seek +300s`, `volume ±26` = ±10 %, `fullscreen`), запросы мимо
системного прокси. Новый фильм закрывает предыдущий VLC ассистента. Через ≤15 с после старта
проверяется `fullscreen` в статусе и при необходимости отправляется команда (окно из фона Windows может
не развернуть). VLC ищется: настройка → реестр `HKLM\SOFTWARE\VideoLAN\VLC` → Program Files → PATH.

## [PC-006] Звук фильма и микрофон: приглушение
Wake word с сигналом (`beep`) и начало `process` → `PLAYER.duck()` (35 % громкости); фаза `waiting` →
`unduck()`. «Громче/тише» во время приглушения меняет громкость, которая вернётся. Фильм стартует
ПОСЛЕ озвучки «Включаю…» (`Reply.after`), пауза — ДО (`Reply.before`).

## [PC-007] Не команда — не перехватывать
Без запущенного VLC «пауза» — не команда; длинная фраза (> 4 слов) без «фильм/кино» не идёт к LLM за
названием и без точного совпадения отдаётся модели («открой секрет, как варить борщ»).
Тесты: `tests/test_pc_control.py` (поддельный VLC `tests/fake_vlc.py`), `tests/test_gui_pc_control.py`.
